# مشروع: فيديو ستوري «تحديثات كلود» — هوية «بقلم دينا»

فيديو موشن جرافيك بمقاس ستوري 1080×1920، مدته 55.3 ثانية، ومبني بـ HTML.
يتحوّل إلى MP4 بأداة Playwright مع ffmpeg.

## الملفات
- `index.html`: المشاهد وتنسيق CSS. المصفوفة `S` فيها المشاهد، وكل مشهد له بداية `s` ونهاية `e` بالثواني، وعنوان للهيدر `t`، و HTML.
- `captions.js`: الكابشن مع توقيته. التوقيت مضبوط على `voice.mp3`، والكلمة اللي بين `<b>` تطلع بالبرتقالي.
- `engine.js`: محرك الحركة. الدالة `render(t)` ترسم الفريم في الثانية t. الحركات تنحدد بالخاصية `data-fx` (pop / up / right / shot / shake / draw)، والتأخير بالخاصية `data-d`.
- `icons.js`: أيقونات SVG، ومعها الدوال المساعدة `card` و`chip` و`spark` و`box`.
- `img/`: لقطات واجهة Claude مع رمز QR لقناة الواتساب. اللقطات مقصوصة من فيديو دقته 1024 بكسل، فدقتها منخفضة.
- `voice.mp3`: التعليق الصوتي.
- `render.py`: الرندر.

## الهوية
- الخلفية `#FAF4EC`، والبرتقالي `#D9775A`، والبني `#A34A2E`، والنص `#2B1A12`.
- الهيدر في الجهة اليمين: شارة K ثم «بقلم دينا AI» ثم فاصل ثم عنوان القسم.
- الخطوط: Tajawal للعربي، و IBM Plex Mono للإنجليزي. الخطان من Google Fonts.

## التشغيل
```bash
pip install playwright && playwright install chromium   # ffmpeg لازم يكون مثبّت
python render.py --stills   # لقطات فحص في stills/
python render.py            # الفيديو النهائي
```

## قواعد
- لا تغيّر توقيت المشاهد ولا توقيت الكابشن، لأنهما مضبوطين على الصوت.
- خل المحتوى داخل المنطقة الآمنة للستوري: لا شيء فوق 110px، ولا شيء تحت 1650px.
- قبل الرندر الكامل، طلّع لقطات الفحص وراجعها بعينك.
